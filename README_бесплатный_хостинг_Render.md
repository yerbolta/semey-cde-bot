# Бесплатный хостинг бота на Render.com

Render даёт бесплатный тариф Web Service без привязки карты. Особенность:
сервис "засыпает" после ~15 минут без обращений и просыпается за 30-50
секунд на первое сообщение после паузы. Для справочного бота это не
проблема — просто первый ответ после долгого перерыва придёт с задержкой.

## Что нужно заранее

1. Токен бота от **@BotFather** в Telegram (см. предыдущую инструкцию)
2. **Anthropic API key** с console.anthropic.com
3. Аккаунт на **GitHub** (бесплатно) — Render разворачивает код из репозитория
4. Аккаунт на **render.com** (бесплатно, вход через GitHub)

## Шаг 1. Загрузите код в GitHub

1. Зайдите на github.com → New repository → назовите, например, `semey-cde-bot`
2. Загрузите туда 3 файла: `app.py`, `requirements.txt` и этот README
   (через кнопку "Add file → Upload files" в интерфейсе GitHub — не
   нужен git в терминале)

## Шаг 2. Создайте Web Service на Render

1. Зайдите на **render.com** → войдите через GitHub
2. **New → Web Service**
3. Выберите репозиторий `semey-cde-bot`
4. Настройки:
   - **Name**: `semey-cde-bot` (или как угодно)
   - **Region**: любой ближайший (Frankfurt подойдёт)
   - **Runtime**: Python 3
   - **Build Command**: `pip install -r requirements.txt`
   - **Start Command**: `gunicorn app:app`
   - **Instance Type**: **Free**
5. В разделе **Environment Variables** добавьте:
   - `TELEGRAM_BOT_TOKEN` = ваш токен от BotFather
   - `ANTHROPIC_API_KEY` = ваш ключ Anthropic
6. Нажмите **Create Web Service**

Render начнёт сборку — займёт 2-5 минут. По завершении вы получите URL
вида `https://semey-cde-bot.onrender.com`

## Шаг 3. Подключите Telegram к вашему серверу (webhook)

Откройте в браузере (замените TOKEN и URL на свои):

```
https://api.telegram.org/botTOKEN/setWebhook?url=https://semey-cde-bot.onrender.com/webhook
```

Если увидите `{"ok":true,"result":true,...}` — всё подключено.

## Шаг 4. Проверьте

Напишите боту в Telegram `/start`. Если сервис только что "проснулся" —
первый ответ может занять 30-50 секунд, дальше — быстро, пока активен.

## Как обновить правила бота в будущем

1. Отредактируйте `SYSTEM_PROMPT` в файле `app.py` на GitHub (можно прямо
   в браузере — кнопка "Edit" на странице файла в репозитории)
2. Render автоматически пересоберёт и передеплоит сервис при изменении
   файла в GitHub (Auto-Deploy включён по умолчанию)

## Ограничения бесплатного тарифа

- Сервис засыпает при простое — первое сообщение после паузы приходит
  с задержкой ~30-50 сек, это нормально для этого сценария
- Память диалога — в оперативной памяти процесса, сбрасывается при
  каждом "просыпании" — подходит для отдельных вопросов, не для долгих
  переписок с сохранением контекста на дни
- Нет проверки, кто пишет боту — ответит любому. Если понадобится
  ограничить круг сотрудников (по Telegram username/ID) — дайте знать,
  добавим простую проверку в `app.py`
- Оплата идёт только за Anthropic API (по токенам) — сам хостинг и сам
  Telegram-бот бесплатны
